# ♣️ Solitaire Klondike (Terminal TUI)

> Projeto desenvolvido como trabalho acadêmico da Universidade, implementando o clássico jogo Paciência Klondike em **C puro**, utilizando a biblioteca **PDCurses/NCurses** para renderização em modo texto (TUI)

---

## ♦️ Sobre o Projeto
O objetivo principal deste projeto é aplicar na prática conceitos fundamentais de **Estruturas de Dados Lineares** (Especificamente Pilhas e Listas Encadeadas dinâmicas) para gerenciar o estado das cartas, as colunas da mesa, as fundações e o monte de descarte, garantindo alto desempenho e baixo consumo de recursos diretamente no terminal.

---

## ♠️ Tecnologias e Ferramentas
* **Linguagem: C** (Padrão C99)
* **PDCurses / NCurses** (Manipulação de interface em modo de texto)
* **GCC / MAKE** (Compilação e automação de build)
* **Git e Github** (Controle de versão)

---

## ❤️ Arquitetura do Projeto
O Código é modularizado para separar estritamente a **lógica de negócio** das **regras de exibição da interface**
